# Work_Review v1.1.3-rc.3（繁體中文）

1.1.3 的第三個候選版本，僅供測試，不取代穩定版 Latest，也不透過穩定自動更新端點提供。請先備份資料，建議使用可捨棄資料驗證清理策略與升級行為。

### 修復
- **macOS 發布 SDK 選擇**：移除固定 CommandLineTools `SDKROOT` 的設定，讓 Tauri 建置使用目前所選 Xcode/xcrun 對應的 SDK，避免 Apple Silicon 與 Intel 建置出現 `libSystem.B.tbd: unknown architecture`；保留明確的系統編譯器路徑。
- **即時上下文隱私邊界**：localhost API 與 MCP 即時上下文遵守應用忽略、內容去識別化與網域排除規則，一般標題也會過濾敏感文字。
- **網域黑名單比對**：解析真正的 URL 主機，修復非預設連接埠、子網域、大小寫與結尾句點造成的漏比對；擷取與查詢使用相同語意。
- **日報取消與狀態收尾**：停止助手中的日報操作時，同步終止已啟動的背景分析工作並清理產生狀態；取消時立即發布桌寵復位狀態，避免殘留模型呼叫或卡在「產生中」。
- **助手收束與回應主體逾時**：最後收束階段回應停止訊號；完整請求（包含回應主體、重試與串流回退）共用絕對截止時間，不再只限制等待回應標頭。
- **切頁後的助手歷史**：背景回答完成後，從最新 store 讀取最終訊息保存，避免歷史會話為空或只有部分內容；切回助手頁後仍可停止進行中的請求。
- **中繼資料清理與索引**：明確啟用後，在啟動及每 6 小時清理到期活動中繼資料、失效相關日報與每小時摘要快取及語意索引；沒有到期活動時，不再清空既有語意索引。
- **macOS 浮動視窗計時**：依連續觀察的實際間隔累計並保留不足一秒的餘量；避免跨會話合併、累計暫停或鎖定畫面期間，以及重複計算同一應用的多個浮動視窗。
- **Claude Sonnet 5.5 相容性**：使用自適應思考，保留帶簽章的原始內容區塊與工具往返順序；分別累積串流思考與正文，補齊空正文回退。
- **一般寫作問題路由**：「如何寫日報」等概念、寫作問題維持一般聊天，不擅自切換至本機工作回顧資料。
- **macOS AX 讀取限制**：限制單次輔助使用訊息的等待時間，降低前景應用無回應時拖慢桌寵與擷取迴圈的風險。
- **相依套件安全更新**：rustls 0.23 系列升級至 `0.23.46`，DOMPurify 升級至 `3.4.17`，納入近期上游安全修復。
- **OCR 全域限頻**（#175）：新建與合併活動共同遵守 `screenshot_interval`，快速切換應用、標題或瀏覽器 URL 不再略過 OCR 冷卻。切換截圖仍會保存，冷卻期間略過的 OCR 不排入佇列補辨識。
- **桌寵高 DPI 定位**：初始定位與展開後的邊界校正，使用目標顯示器的實體像素尺寸與目前展開狀態，避免高縮放、多螢幕時超出工作區。
- **桌寵小尺寸氣泡**：最小氣泡寬度受視窗可用寬度限制。這些修復不代表已確認解決 #177 的卡死恢復後繪製異常。

### 安全預設與驗證邊界
- **中繼資料自動清理預設關閉**：必須在「設定 → 儲存」確認啟用；`0` 天表示永久保留。截圖和中繼資料保留期限相互獨立。升級不會按舊預設值直接刪除歷史；WebDAV 設定同步會保留本機的清理授權與期限。
- **自動回歸檢查**：本機 Windows 已通過 754 項前端及 718 項 Rust 測試、型別檢查、前端正式建置、格式與 Clippy 零警告檢查。發布仍須通過五平台建置與產物完整性門檻。
- **仍需測試**：真實桌面上的隱私過濾、產生中停止、切頁後歷史還原、清理邊界及安裝升級。macOS/Linux 真機互動尚未驗證，RC 不代表穩定版認證。

### macOS 安裝說明
首次開啟若提示「已損壞，無法開啟」，請執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```

# Work_Review v1.1.3 (English)

Stable release consolidating the 1.1.3 release-candidate fixes. Application logic is unchanged from rc.3; only the stable version and release notes are updated. The rc.3 release and tag remain available. Back up your data before upgrading, especially before directory migration or enabling history cleanup.

### Fixed
- **Consistent privacy filtering**: localhost API/MCP live context respects ignored apps, anonymized content and excluded domains; normal window titles also filter sensitive text. Saving privacy keywords no longer discards pending configuration changes.
- **Domain exclusions**: parse the actual URL host, covering non-default ports, subdomains, case differences and trailing dots. Collection and queries share the same matching rules.
- **Cancellation and deadlines**: cancelling a report aborts its spawned analysis task and resets the avatar. Assistant wrap-up listens for cancellation; response bodies, retries and streaming fallback share the absolute request deadline.
- **Assistant navigation and history**: persist the latest completed background answer instead of a stale page snapshot. Returning to the assistant page preserves the ability to stop an active request.
- **Assistant routing**: time-breakdown queries enter work review; conceptual and writing questions such as “How do I write a daily report?” stay in general chat, reducing incorrect permission refusals and unnecessary local-data prompts.
- **Windows OCR** (#175): hide PowerShell windows and use one whole-image recognition pass per cycle. New and merged activities share the `screenshot_interval` cooldown, including rapid app/title/URL switches. Switch screenshots remain saved; skipped OCR is not queued. Oversized input is limited to the native engine's supported dimensions and text boxes map back to the original image.
- **macOS foreground and floating windows** (#181): use in-process NSWorkspace/AXUIElement reads instead of polling with `osascript`, and bound individual AX waits. Floating-window time uses consecutive observed intervals with fractional-second carry, avoiding pauses, lock-screen time and duplicate counting of one app's windows.
- **macOS SDK and packaging**: construct AX constants compatibly with modern SDKs; remove the fixed CommandLineTools `SDKROOT` so the selected Xcode/xcrun determines the SDK for Apple Silicon and Intel builds. The certificate helper script also supports OpenSSL 3.
- **Category editing** (#178): website category changes immediately update overview/history, including domains inferred from titles/OCR. No-match updates report accurately; custom categories can be renamed or deleted before being assigned.
- **Migration and semantic indexing**: validate canonical directory paths before migration and reject dangerous alias/symlink targets. Save AI settings before indexing and improve embedding-configuration errors.
- **UI and avatar bounds**: restore glass-style timeline/category/report overlays and compact KPI typography (#172). Avatar placement uses the target display's physical pixels and expansion state; small bubbles respect available width.
- **Claude Sonnet 5.5**: support adaptive thinking, preserve signed content blocks and tool-call order, and accumulate streamed thinking/text separately with an empty-text fallback.
- **Security dependency updates**: update rustls 0.23 to `0.23.46` and DOMPurify to `3.4.17`, retaining existing HTML sanitization. Windows updates use signed NSIS installers and disable the unused ZIP extraction feature, avoiding the disclosed ZIP extraction vulnerabilities.

### Changes and safe defaults
- **Activity metadata retention**: only after explicit local opt-in, clean expired metadata at startup and every six hours and invalidate associated summaries and semantic indexes. No expired records means the existing semantic index is retained.
- **Automatic cleanup is off by default.** Enable it in Settings → Storage after confirmation. `0` days means keep forever. Screenshot and metadata retention are independent; upgrades do not delete history using an old default, and WebDAV sync preserves this device's cleanup permission and period.
- **Refreshed default AI models**: provider endpoints and default models come from the shared `AiProvider` definition.
- **Release gates**: versions must match current `origin/main`; rebuild Windows, both macOS architectures and both Linux architectures, checking signatures, updater metadata, required assets and Linux GLIBC compatibility.

### Known limitations and validation boundaries
- macOS still uses ad-hoc signing; updates may require screen-recording/accessibility permissions again (#143). This release does not add Developer ID signing or Apple notarization.
- The post-freeze avatar rendering issue (#177) still lacks reproduction details. The bounds fixes do not establish that it is resolved.
- Automated checks and successful builds are not real-desktop acceptance tests. Long-running Windows OCR, installer upgrades, live privacy/cleanup boundaries and macOS/Linux desktop interactions still lack complete validation records.

### macOS install note
If macOS reports the app as damaged on first launch, run:

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```

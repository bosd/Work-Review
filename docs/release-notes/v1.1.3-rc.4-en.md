# Work_Review v1.1.3-rc.4 (English)

Fourth release candidate for 1.1.3, for testing only. It does not replace the stable Latest release and is not offered through the stable automatic-update endpoint. Back up your data; use disposable data when testing cleanup policies and upgrades.

The rc.3 package attempt was not published because its macOS builds selected a CommandLineTools SDK newer than the active Xcode linker. This candidate includes all rc.3 fixes plus the SDK selection correction; the existing rc.3 tag is not rewritten.

### Fixed
- **macOS release SDK selection**: remove the hard-coded CommandLineTools `SDKROOT` override. Tauri builds now resolve the SDK from the selected Xcode/xcrun toolchain, avoiding `libSystem.B.tbd: unknown architecture` errors for both Apple Silicon and Intel builds. Explicit system compiler paths remain in place.
- **Live-context privacy**: localhost API and MCP live context now respect ignored apps, anonymized content, and excluded domains. Sensitive patterns are also filtered from normal window titles.
- **Domain exclusions**: parse the actual URL host so non-default ports, subdomains, case differences, and trailing dots cannot bypass domain exclusions. Collection and queries use the same matching rules.
- **Report cancellation and cleanup**: stopping an assistant report action also aborts its spawned analyzer task and resets generation state. Cancellation immediately publishes the avatar reset state instead of leaving it stuck generating.
- **Assistant wrap-up and response deadlines**: final wrap-up now listens for cancellation. The absolute request deadline covers response bodies, retries, and streaming fallback, not just response headers.
- **Assistant history after navigation**: background completion persists the latest store message rather than a stale component snapshot, preventing empty or partial saved answers. Returning to the assistant page also preserves the ability to stop the active request.
- **Metadata retention and indexing**: when explicitly enabled, expired activity metadata and associated report/summary caches are cleaned at startup and every six hours, and semantic indexes are invalidated. A cleanup with no expired activities no longer clears the existing semantic index.
- **macOS floating-window timing**: accumulate actual elapsed time between consecutive observations, retaining fractional seconds. Avoid merging across sessions, counting pauses or lock-screen time, and counting multiple floating windows from the same app more than once per sample.
- **Claude Sonnet 5.5 compatibility**: use adaptive thinking, preserve signed content blocks and their order across tool calls, and accumulate streamed thinking and text independently with an empty-text fallback.
- **General writing questions**: concept and writing questions such as “How do I write a daily report?” remain in general chat instead of implicitly switching to local work-review data.
- **Bounded macOS AX reads**: limit individual accessibility message waits so an unresponsive foreground app is less likely to stall avatar and collection loops.
- **Dependency security updates**: update rustls 0.23 to `0.23.46` and DOMPurify to `3.4.17`, incorporating recent upstream security fixes.
- **Global OCR cooldown** (#175): new and merged activities share `screenshot_interval`; rapid app, title, or browser URL changes no longer bypass OCR throttling. Screenshots remain saved on switches, but OCR skipped during cooldown is not queued for later recognition.
- **HiDPI avatar bounds**: initial placement and expansion use the target display's physical window dimensions and current expansion state, avoiding off-screen placement at higher scaling or across displays.
- **Small-avatar bubbles**: minimum bubble width is constrained by available window width. These avatar fixes do not establish that the post-freeze rendering issue in #177 is resolved.

### Safe defaults and validation limits
- **Automatic metadata cleanup is off by default.** Enable it explicitly in Settings → Storage after confirmation. `0` days means keep forever. Screenshot and metadata retention are independent. Upgrades do not start deleting history using the previous default value, and WebDAV config sync preserves this device's metadata cleanup permission and retention period.
- **Automated regression checks**: 754 frontend and 718 Rust tests, type checks, production frontend build, formatting, and Clippy with warnings denied passed locally on Windows. Publication still requires the five-platform build and artifact-completeness gates.
- **Still needs testing**: real-desktop privacy filtering, stopping generation, restoring history after navigation, cleanup boundaries, and installer upgrades. macOS/Linux real-desktop interactions have not been verified; this RC is not a stable-release certification.

### macOS install note
If macOS reports the app as damaged on first launch, run:

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```

# Work_Review v1.1.3（繁體中文）

正式發布，彙整 1.1.3 候選版本的修復。業務程式碼與 rc.3 相同，僅更新正式版本號與發布說明；保留既有 rc.3 發布版本及標籤。升級前請備份資料，尤其是在遷移目錄或啟用歷史清理前。

### 修復
- **隱私過濾一致性**：localhost API/MCP 即時上下文遵守應用忽略、去識別化及網域排除規則，一般視窗標題也會過濾敏感文字；隱私關鍵字自動儲存時，不再遺失尚未完成的設定變更。
- **網域排除規則**：解析實際 URL 主機，涵蓋非預設連接埠、子網域、大小寫及結尾句點；擷取與查詢使用相同比對語意。
- **停止產生與回應逾時**：取消日報時同步終止背景分析並重設桌寵；助手收束階段回應停止，回應主體、重試與串流回退共用絕對截止時間。
- **助手切頁與歷史儲存**：背景回答完成後儲存最新最終訊息，避免空白或部分歷史；切回頁面後仍可停止進行中的請求。
- **助手問題路由**：時間分配等資料問題正確進入工作回顧；「如何寫日報」等概念及寫作問題維持一般聊天，減少錯誤的權限拒絕與資料引導。
- **Windows OCR**（#175）：隱藏 PowerShell 視窗，每個週期只執行一次全圖辨識；新建及合併活動共同遵守 `screenshot_interval`，快速切換應用、標題或 URL 不再略過冷卻。切換截圖仍保留，冷卻期間不額外 OCR 或排入佇列補辨識；超長輸入按原生引擎上限截斷，文字框對應回原圖。
- **macOS 前景及浮動視窗**（#181）：改用行程內 NSWorkspace/AXUIElement 讀取，不再輪詢啟動 `osascript`，並限制單次 AX 等待；浮動視窗依連續觀察的實際間隔計時，保留不足一秒餘量，避免暫停、鎖定畫面及同應用多視窗重複累計。
- **macOS SDK 與封裝**：AX 常數採用現代 SDK 相容建構方式，移除固定 CommandLineTools `SDKROOT`，讓 SDK 跟隨所選 Xcode/xcrun，修復 Apple Silicon/Intel 封裝連結錯誤；憑證輔助腳本相容 OpenSSL 3。
- **分類編輯**（#178）：網站分類即時反映於概覽及歷史，回補從標題/OCR 推得的網域；沒有符合紀錄時如實提示，自訂分類不必先套用即可重新命名或刪除。
- **目錄遷移與語意索引**：遷移前檢查正規化路徑，拒絕別名或符號連結指向的危險目標；索引前儲存 AI 設定並改善嵌入設定錯誤提示。
- **介面及桌寵邊界**：恢復玻璃風格下的時間軸、分類與日報浮層定位，修正緊湊 KPI 字級（#172）；桌寵依目標顯示器實體像素與展開狀態定位，小尺寸氣泡受可用寬度限制。
- **Claude Sonnet 5.5**：支援自適應思考，保留簽章內容區塊及工具往返順序，分別累積串流思考和正文，並處理空正文。
- **相依套件安全更新**：rustls 0.23 系列更新至 `0.23.46`，DOMPurify 更新至 `3.4.17`，保留既有 HTML 淨化流程；Windows 更新使用已簽章的 NSIS 安裝包並關閉未使用的 ZIP 解壓功能，避免引入已公告的 ZIP 解壓漏洞。

### 變更與安全預設
- **活動中繼資料保留策略**：僅在本機明確確認啟用後，於啟動及每 6 小時清理到期資料，並失效相關摘要及語意索引；沒有到期紀錄時保留現有索引。
- **自動清理預設關閉**：在「設定 → 儲存」確認啟用；`0` 天表示永久保留。截圖與中繼資料期限獨立，升級不會按舊預設值刪除歷史，WebDAV 同步不覆寫本機清理授權及期限。
- **預設 AI 模型更新**：更新各供應商預設模型，端點及預設模型統一由 `AiProvider` 提供。
- **發布門檻**：版本必須符合目前 `origin/main`；重新建置 Windows、macOS 雙架構及 Linux 雙架構，檢查簽章、更新中繼資料、必要附件及 Linux GLIBC 相容性。

### 已知限制與驗證邊界
- macOS 仍使用臨時簽章，更新後可能需要重新授予螢幕錄製、輔助使用等權限（#143）；本次沒有加入 Developer ID 簽章或 Apple 公證。
- #177 的卡死恢復後桌寵繪製異常仍缺乏重現資訊，本版邊界修復不代表該問題已確認解決。
- 自動檢查與成功建置不等於真機驗收；Windows OCR 長時間執行、安裝升級、真實桌面隱私及清理邊界，以及 macOS/Linux 真機互動仍缺少完整驗證紀錄。

### macOS 安裝說明
首次開啟若提示「已損壞，無法開啟」，請執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
